# Productivity Dashboard 🧠✅

A lightweight **Productivity Dashboard** built using **HTML, CSS, and Vanilla JavaScript**.  
It combines daily essentials like **weather updates, task management, daily goals planning, motivational quotes, and a Pomodoro timer** — all in one place.

---

## ✨ Features

1. **Home Weather Widget**  
   Displays live weather on the home page (based on selected/default location).

2. **Task Manager (To-Do List)**  
   Add, update, complete, and delete tasks to stay organized.

3. **Daily Goals Planner**  
   Plan your day by listing goals and tracking progress.

4. **Motivational Quotes (API)**  
   Fetches fresh motivational quotes using a public Quotes API.

5. **Pomodoro Timer**  
   Focus timer with work/break sessions to improve productivity.
   
---

## 🛠 Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
- **APIs**: Weather API + Quotes API
